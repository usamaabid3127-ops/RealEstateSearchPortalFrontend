# Real Estate Portal - Frontend

A React-based frontend for a real estate portal application that allows users to browse properties, save favorites, and view property details.

## Features

- Property search and filtering
- User authentication (login/register)
- Favorite properties management
- Responsive design
- Property detail views

## Technologies Used

- React 18
- TypeScript
- React Router DOM
- Axios for API calls
- CSS3 with custom styling

## Backend API

This frontend connects to a .NET Core Web API backend. You can find the backend repository [here](https://github.com/your-username/real-estate-backend).

## Prerequisites

Before running this application, make sure you have:

- Node.js (version 14 or higher)
- npm or yarn package manager
- The backend API running (see backend repository for setup)
